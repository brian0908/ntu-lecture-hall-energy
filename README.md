# 臺大教學館節能規劃 — 冷氣用電分析與政策缺口

**課程：** 環境與能源的資料科學  
**角色扮演：** 能源數據顧問公司，向台大校方提案  
**核心論點：** 台大目前沒有冷氣*使用*規範（只有購買規範），我們量化若落實政府 26°C 標準的節電潛力，並提出具體的政策建議

---

## 背景與問題框架

透過與台大總務處的訪談，確認了以下現況：

- **台大有購買規範，但沒有使用規範**：目前規定的是冷氣噸數與空間面積的比例，但對「幾度開、幾點關」沒有正式規定
- **過去曾有非正式提醒**（如 10 點後開、設定 28°C），但現在基本上沒有
- **教學館空調由教務處課務組管理**，非總務處；各系館各自管理
- **普通高壓空調電表**：實測範圍 10–70 kW，但永續辦公室估算普通教學館整棟空調為 117 kW；差距確認此電表只量到整棟多條空調電路中的一條子電路，**不能用來驗證 117 kW 的大小**。其後端電盤也非總務處維護，可能含非空調用電。此電表的用途僅限於**拐點分析推算設定溫度**

這個政策缺口（governance gap）是本專案的核心切入點：*沒有規範，就無從檢驗合規性，也無從估算超額耗電有多嚴重。*

## 分析架構與現況

### 核心問題

台大沒有冷氣使用規範，若落實政府 26°C 標準（同時搭配延後開機時段），四大講堂乃至全校每年可節省多少用電？

### 分析流程

```
資料前處理（01）
    ↓
EDA + 分季拐點分析推算設定溫度（02）
    ↓
採用永續辦公室分解結果（03，待補充）
    ↓
26°C 反事實計算：全年單一設定（04）／分季設定（05，主要結果）
    ↓
政策建議（簡報製作中）
```

### 各階段說明

**Stage 1 — 資料前處理** `01_data_loading_cleaning.ipynb` ✅

- 載入所有電表資料（HTML-XLS 與 binary XLS 兩種格式）
- 清除異常值（負功率、極端峰值、電表重置）；補插短暫缺值（≤3小時），長缺值保留為 NaN
- 匯出 `cleaned_data/*.parquet` 供後續使用

**Stage 2 — EDA + 設定溫度推算** `02_eda.ipynb` ✅

- 合併電表與 CWA 逐時氣溫資料（台北站）
- 將每個時間點分類為 16 種「用電情境 × 日型」組合，計算八項分項用電（館舍基礎 / 設備待機 / 人員設備 / 人員空調）
- **拐點分析（Section 三）：** 普通 AC kW vs 室外溫度散佈圖（上課日、上課時段），全年聚合拐點推估設定溫度約 **24°C**
- 補充 EDA：各館用電熱力圖（月份 × 時段）、假日 vs 平日負載曲線、年度用電趨勢

**Stage 3 — 永續辦公室方法** `03_sustainability_method.ipynb` 🔴

- 目前只有載入 `館舍用電基礎值.xlsx`，尚未撰寫實質內容
- 待補：說明永續辦公室的 Dayoff × 溫度分層 × 75th percentile 分解邏輯；說明我們**不直接比較 kW 大小**（子電路 vs 整棟），而是驗證溫度反應形狀（拐點一致性）

**Stage 4 — 全年反事實（基準）** `04_counterfactual.ipynb` ✅

- 單一年均設定溫度 24°C；AC 有效運行時段：上課日 × 08–22h × 4–10月 × T_outdoor > 24°C → 年均 **1,222 hr/yr**
- CDH 節電比例：`1 − CDH_26 / CDH_24 = 36%`（2016–2025 平均）
- 全校 145 棟推估：**節電 3.58 GWh/yr、節費 1,252 萬元/yr、減碳 1,767 公噸 CO₂/yr**
- 敏感度：T_set 23°C → 47% 節電；T_set 25°C → 21% 節電
- ⚠️ Section 九的摘要表格為佔位符，尚未填入計算結果

**Stage 5 — 分季反事實（主要結果）** `05_seasonal_ac_temperature_savings.ipynb` ✅

- 對每個學期分別以**兩段分段線性回歸**（piecewise linear regression）推估設定溫度：

  | 學期 | 設定溫度 | 說明 |
  |---|---|---|
  | 下學期（2–6月）| **24.0°C** | 節電潛力最大 |
  | 上學期（9–12月）| **26.1°C** | 已接近標準，節電空間小 |
  | 暑假（7–8月）| **29.6°C** | 幾乎無降溫需求 |

- 量化兩項政策的節電效益：
  1. **調升至 26°C**（溫度管制）
  2. **延後至 09:00 開機**（時段管制，現假設 08:00 開）

- 主要結果（全校 145 棟）：

  | 措施 | 年節電量 | 年節費 |
  |---|---|---|
  | 調升 26°C | **2.48 GWh** | **8.7 百萬元** |
  | 延後開機 | **0.58 GWh** | **2.0 百萬元** |
  | 兩措施合計 | **3.06 GWh** | **10.7 百萬元** |

- 04 與 05 的差異：04 的全年 24°C 假設高估了上學期（9–12月）的節電潛力，因為那個學期實際設定溫度已接近 26°C。**05 是更準確的估算，作為正式 pitch 的主要結果使用。**
- ⚠️ Section 七的碳排輸出顯示「1 公噸」，疑似計算單位錯誤，待修正


### 第三步：開啟筆記本開始工作

在左側檔案列表點擊 `.ipynb` 檔案，VS Code 會直接開啟 Jupyter 筆記本介面，不需要另開瀏覽器。

先清除筆記本輸出：點筆記本上方工具列的 **⋯ → Restart Kernel and Clear All Outputs → 存檔（Ctrl+S）**

1. 在「Changes」區塊，點 **＋** 號將檔案加入暫存（等同 `git add`）
2. 在上方輸入框填寫說明，例如：`新增溫度與用電散佈圖`
3. 點 **✓ Commit** 按鈕
4. 點 **Sync Changes**（或 **Push**）上傳

第一次 push 會跳出 GitHub 登入視窗，登入自己的帳號即可。
